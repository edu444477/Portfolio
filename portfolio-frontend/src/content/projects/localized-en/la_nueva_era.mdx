# La Nueva Era — Final Degree Project

## Overview

**La Nueva Era** is my Final Degree Project: a complete platform for buying, selling and trading second-hand physical video games. It includes a public marketplace, a user system with cart and wishlist, a newsletter, and a full administration panel for managing shifts, employees and incidents (HR module).

## Architecture

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   React SPA     │────▶│   Flask API     │────▶│  PostgreSQL     │
│   (Vite)        │     │   (RESTful)     │     │  (MySQL in PA)  │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                              │
                              ▼
                       ┌─────────────────┐
                       │     Redis       │
                       │  (Cache/Session)│
                       └─────────────────┘
```

## Core Features

### Marketplace
- Product catalogue with filters by category, game and price
- Product page with images, description, condition and stock
- Real-time search

### User Area
- Registration/login with JWT (access + refresh tokens)
- Persistent cart (localStorage + server sync)
- Wishlist
- Order history and details
- Trade-in system between users
- Ratings and reviews

### Newsletter
- Double opt-in subscription
- Subscriber management in the admin panel

### Administration Panel (HR)
- Company management (location, geofencing radius)
- Shifts and time slots per day
- Employee CRUD (roles, shifts, company)
- Attendance records with geolocation validation
- Incidents and justification documents

## Tech Stack In Detail

| Layer | Technology | Rationale |
|-------|------------|-----------|
| Frontend | React 18 + Vite | DX, HMR, optimised bundle |
| Routing | React Router v6 | SPA routing, lazy loading |
| State | Context API + useReducer | No extra dependencies, sufficient |
| Styling | CSS Modules + Variables | Scoping, theming, no runtime |
| Backend | Flask 3 + Flask-RESTful | Lightweight, mature, full control |
| Auth | Flask-JWT-Extended | Standard JWT, refresh, blacklist |
| ORM | SQLAlchemy 2.0 + Alembic | Type hints, versioned migrations |
| DB | MySQL (PythonAnywhere) / PostgreSQL (local) | Relational, ACID transactions |
| Cache | Redis (Upstash) | Sessions, rate limiting, queues |
| Deploy | PythonAnywhere (WSGI) / Docker | Free, straightforward for the project |

## Key Decisions

1. **API-first**: the entire frontend consumes the REST API, enabling future mobile clients.
2. **Separate schemas**: in PostgreSQL I use `search_path` to isolate e-commerce (`tfg`) from HR (`tfg_rrhh`).
3. **Dual validation**: Zod on the frontend + Marshmallow/Pydantic on the backend.
4. **Security**: Bcrypt for passwords, JWT with short expiry + refresh, restrictive CORS, rate limiting.
