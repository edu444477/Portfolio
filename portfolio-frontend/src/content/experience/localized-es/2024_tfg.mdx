# Trabajo de Fin de Grado: La Nueva Era

## Contexto

Proyecto individual de fin de grado desarrollado durante 5 meses, cubriendo todo el ciclo de vida: requisitos, diseño, implementación, testing, documentación y despliegue.

## Responsabilidades

- **Arquitectura completa**: Definición de stack, patrones, estructura de carpetas
- **Backend**: API REST, autenticación, lógica de negocio, migraciones BD
- **Frontend**: SPA React, componentes reutilizables, estado global, responsive
- **DevOps**: Docker, CI/CD básico, despliegue en PythonAnywhere/Render
- **Documentación**: Memoria técnica (100+ páginas), manual de usuario, API docs

## Retos Superados

1. **Complejidad de dominio**: E-commerce + RRHH en una app → schemas separados en BD
2. **Autenticación robusta**: JWT con refresh tokens, rotación, blacklisting en Redis
3. **Estados complejos frontend**: Carrito, wishlist, intercambio → Context + useReducer
4. **Despliegue real**: PythonAnywhere gratis → limitaciones WSGI, archivos estáticos, MySQL
