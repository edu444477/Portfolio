# Final Degree Project: La Nueva Era

## Context

An individual final degree project developed over five months, covering the full lifecycle: requirements, design, implementation, testing, documentation and deployment.

## Responsibilities

- **Full architecture**: stack definition, patterns, folder structure
- **Backend**: REST API, authentication, business logic, database migrations
- **Frontend**: React SPA, reusable components, global state, responsive design
- **DevOps**: Docker, basic CI/CD, deployment on PythonAnywhere/Render
- **Documentation**: technical report (100+ pages), user manual, API docs

## Challenges Overcome

1. **Domain complexity**: e-commerce + HR in one app → separate schemas in the database
2. **Robust authentication**: JWT with refresh tokens, rotation, blacklisting in Redis
3. **Complex frontend state**: cart, wishlist, trade-in → Context + useReducer
4. **Real deployment**: free PythonAnywhere → WSGI limitations, static files, MySQL
